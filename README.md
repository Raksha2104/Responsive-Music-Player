# Modern Music Player

## Overview

The Modern Music Player is a responsive web-based application developed using HTML, CSS, and JavaScript. This project provides an interactive music listening experience with essential audio playback controls and a visually appealing user interface. Users can play, pause, skip, and navigate through songs while viewing song information such as title, artist name, and duration.

The application demonstrates front-end development concepts including DOM manipulation, event handling, responsive design, and media control using JavaScript. The project is designed to offer a smooth and user-friendly experience across different devices and screen sizes.

## Features

* Play and Pause audio tracks
* Next and Previous song navigation
* Dynamic display of song title and artist information
* Real-time progress bar tracking
* Adjustable volume control
* Playlist management
* Autoplay functionality
* Responsive design for mobile and desktop devices
* Interactive and modern user interface
* Smooth transitions and hover effects

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
